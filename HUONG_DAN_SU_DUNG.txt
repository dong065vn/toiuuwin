┌─────────────────────────────────────────────────────────────────────────┐
│  1. 💻 SYSTEM MODULE - HỆ THỐNG                                        │
└─────────────────────────────────────────────────────────────────────────┘

CHỨC NĂNG CHÍNH:
----------------
✓ Hiển thị thông tin hệ thống (CPU, RAM, OS, Disk)
✓ Process Manager đầy đủ
✓ Realtime monitoring (CPU, RAM, Disk, Network)
✓ Quản lý processes (End/Suspend/Resume)

CÁCH SỬ DỤNG:
-------------
A. Xem Thông Tin Hệ Thống:
   • Thông tin tự động hiển thị khi mở module
   • Bao gồm: OS, CPU, RAM, Disk

B. Realtime Monitoring:
   • Cập nhật mỗi giây
   • Hiển thị:
     - CPU usage (%)
     - RAM usage (%, GB/GB)
     - Disk usage (%, GB/GB)
     - Network speed (↓ KB/s | ↑ KB/s)
     - Số lượng processes đang chạy

C. Process Manager:
   1. Tìm kiếm process: Gõ tên vào ô "🔍 Tìm kiếm"

   2. Sắp xếp:
      • CPU: Xem processes dùng CPU nhiều nhất
      • Memory: Xem processes dùng RAM nhiều nhất
      • Name: Sắp xếp theo tên

   3. Thao tác:
      • Chọn process → Click "■ End Process" để kết thúc
      • Click "⏸️ Suspend" để tạm dừng
      • Click "▶ Resume" để tiếp tục
      • Click "📊 Details" để xem chi tiết

   4. Làm mới: Click "Làm mới" để cập nhật danh sách

CẢNH BÁO:
---------
⚠️ KHÔNG end các process hệ thống:
   - explorer.exe (Windows Explorer)
   - csrss.exe (Client Server Runtime)
   - winlogon.exe (Windows Logon)
   - services.exe (Services Control Manager)
   - svchost.exe (Service Host)

MẸO:
----
💡 Nếu máy chậm, sắp xếp theo CPU để tìm ứng dụng gây tốn CPU
💡 Nếu hết RAM, sắp xếp theo Memory để tìm ứng dụng ngốn RAM

CÁCH SỬ DỤNG:

   1. Click "🔍 Kiểm tra toàn diện"
   2. Đợi 10-30 giây
   3. Xem kết quả:
      • Overall health score (💚/💛/🧡/❤️)
      • Health bars cho từng hạng mục:
        - CPU Health
        - Memory Health
        - Disk Health
        - Network Health
        - Security Health
      • Danh sách vấn đề phát hiện

   1. Click "🚀 Quick Benchmark"
   2. Test:
      • CPU speed
      • Memory availability
      • Disk space
   3. Xem kết quả trong card "Kết quả Benchmark"

   1. Click "🔧 Sửa lỗi tự động"
   2. Xác nhận
   3. Ứng dụng sẽ:
      • Dọn temp files
      • Chạy Disk Cleanup
      • Reset network cache

D. Dọn Dẹp Hệ Thống:
   1. Click "🧹 Dọn dẹp hệ thống"
   2. Xóa:
      • Temp files
      • Prefetch
      • Recycle Bin
      • Chạy Disk Cleanup

ĐÁNH GIÁ HEALTH SCORE:
----------------------
90-100: 💚 Xuất sắc - Hệ thống hoạt động tối ưu
70-89:  💛 Tốt - Hệ thống ổn định
50-69:  🧡 Trung bình - Cần chú ý
0-49:   ❤️ Cần cải thiện - Có vấn đề nghiêm trọng

MẸO:
----
💡 Chạy Health Check định kỳ 1 tuần 1 lần
💡 Nếu score < 70, đọc khuyến nghị và khắc phục
💡 Benchmark trước/sau tối ưu để so sánh hiệu quả

CHỨC NĂNG CHÍNH:
----------------
✓ Quản lý chương trình tự động chạy khi Windows khởi động
✓ Hỗ trợ cả Registry và Startup Folder
✓ Enable/Disable/Delete startup items
✓ Tìm kiếm và lọc
✓ Mở file location

CÁCH SỬ DỤNG:
-------------
A. Xem Danh Sách Startup:
   • Module tự động load tất cả startup items từ:
     - HKCU\Run
     - HKLM\Run
     - RunOnce keys
     - Startup folders (User & Common)

B. Tìm Kiếm:
   1. Gõ tên chương trình vào ô "🔍 Tìm kiếm"
   2. Danh sách tự động lọc

C. Vô Hiệu Hóa Startup Item:
   1. Chọn item trong danh sách
   2. Click "⛔ Disable"
   3. Xác nhận
   4. Item sẽ không chạy khi khởi động Windows

D. Kích Hoạt Lại:
   1. Chọn item đã disable
   2. Click "✅ Enable"

E. Xóa Vĩnh Viễn:
   1. Chọn item
   2. Click "🗑️ Delete"
   3. ⚠️ Cẩn thận: Không thể hoàn tác!

F. Mở Vị Trí File:
   1. Chọn item
   2. Click "📂 Open Location"
   3. Windows Explorer sẽ mở và highlight file

G. Tắt Tất Cả (Cẩn thận!):
   1. Click "Tắt tất cả"
   2. Xác nhận
   3. ⚠️ Sẽ disable TẤT CẢ startup items

NÊN DISABLE:
------------
✅ Game launchers:
   • Steam
   • Epic Games Launcher
   • Origin
   • Battle.net

✅ Chat/Communication apps (nếu không dùng ngay):
   • Discord
   • Skype
   • Telegram Desktop
   • Slack

✅ Update services:
   • Adobe Update
   • Java Update
   • Google Update (nếu không cần)

✅ Cloud sync (nếu không dùng):
   • Dropbox
   • OneDrive (nếu không dùng)
   • Google Drive

KHÔNG NÊN DISABLE:
------------------
❌ Antivirus/Security:
   • Windows Defender
   • Antivirus của bạn
   • Firewall

❌ Drivers quan trọng:
   • Graphics card drivers (NVIDIA/AMD/Intel)
   • Audio drivers (Realtek)
   • Touchpad drivers

❌ Cloud backup quan trọng:
   • Cloud backup service bạn đang dùng
   • Sync tools cần thiết

❌ System tools:
   • CTF Loader (Windows language services)
   • Windows Security

KẾT QUẢ MONG ĐỢI:
------------------
• Tốc độ khởi động: Giảm 20-50% thời gian
• RAM khi idle: Giảm 200-500MB
• Máy phản hồi nhanh hơn sau boot

CHỨC NĂNG CHÍNH:

CÁCH SỬ DỤNG:
-------------
A. Xem Danh Sách Services:
   • Module tự động load tất cả services
   • Hiển thị:
     - Tên service
     - Tên hiển thị
     - Trạng thái (Running/Stopped)
     - Startup Type (Automatic/Manual/Disabled)
     - Mô tả

B. Lọc Services:
   • All: Tất cả services
   • Running: Chỉ services đang chạy
   • Stopped: Chỉ services đã dừng
   • Recommended: Services được khuyến nghị tắt để tối ưu

C. Tìm Kiếm:
   1. Gõ tên service vào ô "Tìm kiếm"
   2. Tìm theo tên hoặc mô tả

D. Start/Stop Service:
   1. Chọn service
   2. Click:
      • "▶️ Start" - Chạy service
      • "■ Stop" - Dừng service
      • "🔄 Restart" - Khởi động lại

E. Thay Đổi Startup Type:
   1. Chọn service
   2. Click:
      • "⚙️ Auto" - Tự động chạy khi boot
      • "✋ Manual" - Chạy khi cần
      • "⛔ Disabled" - Vô hiệu hóa

F. Tối Ưu Tự Động:
   1. Click "🚀 Tối ưu tự động"
   2. Xác nhận
   3. Ứng dụng sẽ tự động disable các services không cần thiết

SERVICES NÊN TẮT (AN TOÀN):
---------------------------
✅ DiagTrack (Connected User Experiences and Telemetry)
   • Thu thập dữ liệu sử dụng
   • Không ảnh hưởng chức năng Windows

   • Chỉ cần cho Windows Store apps
   • An toàn tắt nếu không dùng Store

✅ lfsvc (Geolocation Service)
   • Định vị vị trí
   • Tắt nếu lo ngại privacy

✅ MapsBroker (Downloaded Maps Manager)

   • Tắt nếu không dùng Maps app

✅ Xbox services (nếu không chơi game Xbox):
   • XblAuthManager
   • XblGameSave
   • XboxGipSvc
   • XboxNetApiSvc

✅ Windows Search (nếu không dùng):
   • WSearch
   • Cẩn thận: Ảnh hưởng Start Menu search

✅ Print Spooler (nếu không có máy in):
   • Spooler
   • Tắt nếu không in ấn

SERVICES KHÔNG NÊN TẮT:
-----------------------
❌ Windows Update (wuauserv)
   • Cập nhật bảo mật quan trọng
   • Chỉ tắt nếu bạn là expert

❌ Windows Defender:
   • WinDefend
   • Bảo vệ khỏi malware

❌ Windows Firewall:
   • MpsSvc (Windows Firewall)
   • Bảo vệ mạng

❌ DHCP Client
   • Dhcp
   • Cần để kết nối mạng

❌ DNS Client
   • Dnscache
   • Cần để truy cập internet

❌ Plug and Play
   • PlugPlay
   • Nhận diện thiết bị

❌ Remote Procedure Call (RPC)
   • RpcSs
   • Core Windows service

STARTUP TYPE KHUYẾN NGHỊ:
-------------------------
• Automatic: Services quan trọng (Defender, Firewall, DHCP, DNS)
• Manual: Services dùng thỉnh thoảng (Print Spooler)
• Disabled: Services không cần (Xbox, Telemetry, Maps)

================================================================================
                       VII. XỬ LÝ SỰ CỐ
================================================================================

SỰ CỐ 1: MÁY CHẬM SAU KHI TỐI ƯU
=================================
NGUYÊN NHÂN:
• Tắt nhầm service quan trọng
• Tối ưu quá mức

GIẢI PHÁP:
1. Mở Optimization → Click "↺ Khôi phục mặc định"
2. Mở Privacy → Click "↺ Khôi phục mặc định"
3. Mở Services → Tìm và Start các services đã disable:
   • DHCP Client → Automatic → Start
   • DNS Client → Automatic → Start
   • Windows Search → Automatic → Start (nếu cần)
4. Khởi động lại máy

Nếu vẫn lỗi:
5. Restore từ System Restore Point:
   • Mở System Properties
   • System Protection tab
   • System Restore
   • Chọn restore point trước khi optimize


SỰ CỐ 2: KHÔNG KẾT NỐI ĐƯỢC MẠNG
=================================
NGUYÊN NHÂN:
• Tắt DHCP Client hoặc DNS Client

GIẢI PHÁP:
1. Mở Services Manager
2. Tìm "DHCP Client"
   • Set to "Automatic"
   • Click "Start"
3. Tìm "DNS Client"
   • Set to "Automatic"
   • Click "Start"
4. Mở Network Tools → Click "Reset Network"
5. Khởi động lại máy


SỰ CỐ 3: START MENU KHÔNG SEARCH ĐƯỢC
======================================
NGUYÊN NHÂN:
• Tắt Windows Search service
• Tắt Web Search trong Privacy Tweaks

GIẢI PHÁP:
1. Mở Services Manager
2. Tìm "Windows Search"
   • Set to "Automatic"
   • Click "Start"
3. Đợi vài phút để rebuild index
4. Test lại Start Menu search


SỰ CỐ 4: WINDOWS UPDATE KHÔNG CHẠY
===================================
NGUYÊN NHÂN:
• Disabled Windows Update service

GIẢI PHÁP:
1. Mở Services Manager
2. Tìm "Windows Update" (wuauserv)
   • Set to "Automatic"
   • Click "Start"
3. Hoặc:
   • Mở Optimization
   • Tick "✅ Khôi phục tất cả tính năng"
   • Click "Khôi phục mặc định"


SỰ CỐ 5: ỨNG DỤNG BỊ CRASH / KHÔNG CHẠY
========================================
NGUYÊN NHÂN:
• Thiếu quyền truy cập (Camera/Mic)
• Thiếu service cần thiết

GIẢI PHÁP:
1. Mở Privacy Tweaks → Click "↺ Khôi phục mặc định"
2. Restart ứng dụng
3. Nếu vẫn lỗi:
   • Mở Services → Start các services liên quan
   • Reinstall ứng dụng


SỰ CỐ 6: MÁY KHÔNG BOOT ĐƯỢC
=============================
NGUYÊN NHÂN:
• Tắt service core quan trọng (hiếm gặp)

GIẢI PHÁP:
1. Khởi động vào Safe Mode:
   • Nhấn F8 khi boot (hoặc Shift + Restart)
   • Chọn "Safe Mode"

2. Trong Safe Mode:
   • Mở Services (Win + R → services.msc)
   • Enable lại các services đã disable
   • Hoặc System Restore

3. Nếu không vào được Safe Mode:
   • Boot từ USB Windows
   • Chọn "Repair your computer"
   • System Restore


SỰ CỐ 7: QUÊN ĐÃ TẮT GÌ
========================
GIẢI PHÁP:
• Kiểm tra Console log (nếu còn mở app)
• Hoặc:
  1. Services → Filter "Disabled" → Xem danh sách
  2. Startup → Xem items đã disable
  3. System Restore về trước đó
