I. YÊU CẦU TRƯỚC KHI BUILD
--------------------------
1. Python 3.8+ đã cài đặt
2. Đã cài đặt dependencies:
   > pip install -r requirements.txt

3. PyInstaller sẽ tự động cài trong quá trình build


II. CÁCH BUILD
--------------

CÁCH 1: Chạy build script (KHUYẾN NGHỊ)
----------------------------------------
1. Mở Terminal/PowerShell trong thư mục dự án
2. Chạy lệnh:
   > python build_app.py

3. Đợi 2-5 phút
4. File EXE sẽ ở trong thư mục: dist\WindowsOptimizerPro_v6.0.exe


CÁCH 2: Build thủ công với PyInstaller
---------------------------------------
1. Cài PyInstaller:
   > pip install pyinstaller

2. Chạy lệnh build:
   > pyinstaller --name=WindowsOptimizerPro_v6.0 ^
     --onefile ^
     --windowed ^
     --manifest=app.manifest ^
     --add-data=modules;modules ^
     --add-data="Office_Tool_with_runtime_v10.28.29.0_x64;Office_Tool_with_runtime_v10.28.29.0_x64" ^
     --add-data="PITVN_AVLtool;PITVN_AVLtool" ^
     --add-data="PITVN Community Resources;PITVN Community Resources" ^
     --noconsole ^
     --clean ^
     app.py

VI. CÁCH CHẠY EXE
-----------------
1. Vào thư mục dist/
2. Right-click "WindowsOptimizerPro_v6.0.exe"
3. Chọn "Run as Administrator"
4. Click "Yes" ở UAC prompt
5. App sẽ khởi động


VII. XỬ LÝ LỖI BUILD
---------------------

LỖI 1: "PyInstaller not found"
-------------------------------
GIẢI PHÁP:
> pip install pyinstaller


LỖI 2: "Failed to execute script"
----------------------------------
NGUYÊN NHÂN: Thiếu dependencies
GIẢI PHÁP:
> pip install -r requirements.txt
> Chạy lại build


LỖI 3: Build thành công nhưng EXE không chạy
---------------------------------------------
NGUYÊN NHÂN: Thiếu quyền admin
GIẢI PHÁP:
• PHẢI chạy as Administrator
• Right-click EXE → Run as Administrator


LỖI 4: "Module not found" khi chạy EXE
---------------------------------------
NGUYÊN NHÂN: Thiếu hidden imports
GIẢI PHÁP:
• Mở build_app.py
• Thêm vào phần --hidden-import:
  --hidden-import=<tên_module_thiếu>


LỖI 5: Resources không tìm thấy
--------------------------------
NGUYÊN NHÂN: Đường dẫn không đúng
GIẢI PHÁP:
• Kiểm tra 3 folders có đúng tên:
  - Office_Tool_with_runtime_v10.28.29.0_x64
  - PITVN_AVLtool
  - PITVN Community Resources
• Chạy lại build


VIII. TỐI ƯU BUILD
------------------

GIẢM KÍCH THƯỚC EXE:
--------------------
1. Loại bỏ modules không dùng:
   • Comment các module không cần trong app.py
   • Xóa imports không dùng

2. Nén với UPX:
   > pip install pyinstaller[encryption]
   > Thêm flag: --upx-dir=<path_to_upx>

3. Exclude libraries không cần:
   • Thêm: --exclude-module=<tên_module>


TĂNG TỐC BUILD:
---------------
1. Sử dụng cache:
   • Xóa flag --clean khi build lại

2. Build trên SSD:
   • Copy project sang SSD trước khi build
